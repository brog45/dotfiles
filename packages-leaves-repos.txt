# Format: <extrepo repository> <package> [<package>...]

# install-packages-leaves enables a repository (via extrepo) only when one of
# its packages is listed in packages-leaves.txt, is not installed, and cannot
# already be found by apt. A repository you configured some other way is
# therefore never added twice -- two sources for one URL with different
# signing keys make `apt-get update` fail outright.
